# DSH Remote

### [Open the Android download page](https://aercherc.github.io/dsh-remote/android/)

[Android download page](https://aercherc.github.io/dsh-remote/android/) · [中文](./README.md)

Securely use the **DeepSeek Harness (DSH)** running on your computer from a phone or tablet browser.

`dsh-remote` runs a Remote Gateway on your computer and establishes a public HTTPS entry through a Cloudflare Quick Tunnel. Once your phone has paired, you can keep accessing the DSH Web UI, watch Agent progress, continue conversations, handle actions that need your confirmation, and pick workspaces.

Projects, sessions, tools, files, and Agents still run on the computer — the mobile device only provides remote access.

## Features

### 🤖 Android app

- [Open the Android download page](https://aercherc.github.io/dsh-remote/android/) to review the version and installation requirements before downloading (Android 8.0+).
- Scan the QR code shown on the computer to connect from the app's dedicated WebView.
- The app and browser share the same pairing flow, Device Sessions, and gateway security boundary.

### 📱 Phone / tablet remote access

- Connect from either a mobile browser or the DSH Remote Android app.
- Public HTTPS connection via Cloudflare Quick Tunnel.
- No public IP, port forwarding, or extra VPS required.
- The Remote Gateway listens on the loopback address only, and public requests must be authenticated first.

### 🔐 One-time pairing

- Enabling remote control generates a QR code and an 8-digit pairing code.
- Pairing tickets are valid for 5 minutes by default.
- Scan the QR code or type in the pairing code.
- The ticket is invalidated immediately after a successful pairing.
- You can generate a new pairing code at any time; the old tickets are invalidated together with it.

### 🔢 Long-term pairing code

For a phone or tablet you use regularly over a longer period.

- Coexists with one-time pairing; switch between the two in the settings page.
- Supports both QR code and manual entry.
- The long-term code stays valid until you manually replace it, and keeps working after a DSH restart.
- A random 9-character code is generated by default.
- Custom 6–12 character alphanumeric codes (`A-Z`, `0-9`) are supported.
- Replace the long-term code in one click — the old code and its QR code are invalidated immediately.
- Replacing the long-term code only affects future pairings; it does not disconnect devices that are already authorized.

### 💻 Per-device authorization

- Every paired device gets its own Device Session.
- View the list of authorized devices.
- Revoke a single device.
- Or revoke all devices at once.
- Obtaining the public URL does not by itself grant access — a device still has to pair first.

### 🗂️ Remote workspace picker

- Browse the computer's directories from the phone and choose a DSH workspace.
- On Windows, the roots of different drives can be browsed.
- Actual file access is still governed by the host operating system's permissions.

### 📡 Quick Tunnel status & auto recovery

- Shows the download, verification, starting, connecting, and ready states.
- The usable remote address and pairing info appear only after the Cloudflare Edge has actually confirmed the connection.
- Continuously monitors the Tunnel Edge connection.
- On a brief network hiccup, keeps the current public URL and device authorizations and waits for `cloudflared` to recover automatically.
- Recent loss / recovery events and their durations are visible.
- If the `cloudflared` process actually exits, the current public entry is closed and you are prompted to restart.

### 🌐 cloudflared download & network adaptation

The project prepares the `cloudflared` binary required by Quick Tunnel automatically:

- Checks whether an existing local `cloudflared` is trusted and usable.
- Downloads are verified with a pinned version and SHA-256.
- On Windows, the Authenticode signature is additionally verified.
- A corrupted cached file is re-downloaded automatically.
- Shows download size, speed, source, and the current network path.
- Official source with mirror fallback.
- Three download network modes: automatic, direct, and custom proxy.

### 🔄 Update management

- Version check and update status are available in the settings page.
- Updates are applied via the official `dsh plugin` command.
- The actually installed version is re-verified after installation.
- A running DSH is never restarted automatically — the update takes effect after you restart manually.

### 🪟 DSH Desktop installation

- The plugin can be installed with DSH's help directly inside DSH Desktop.
- No need to quit Desktop or open a terminal to run an installer script.
- Just send an install request with this repository's address in the DSH conversation, and DSH completes the installation.
- Once installed, go straight to **Settings → Remote Control** and enable remote access.

## How it works

```text
Phone / tablet browser
        │
        │ HTTPS
        ▼
Cloudflare Quick Tunnel
        │
        ▼
Remote Gateway (127.0.0.1)
        │
        ├─ One-time pairing
        ├─ Long-term pairing code
        ├─ Device Session
        └─ Request authentication / reverse proxy
        │
        ▼
DeepSeek Harness

Projects / sessions / Agents / tools / files stay on the computer
```

The Quick Tunnel brings public HTTPS traffic back to the computer; the Remote Gateway authenticates visitors and proxies the authenticated requests to the DSH running locally.

`cloudflared` always targets the Remote Gateway, never DSH directly, so public requests cannot bypass pairing and device-session authentication to reach DSH.

## Quick start

`dsh-remote` is used as a DSH plugin. After installation, open in DSH:

```text
Settings → Remote Control
```

Enable remote control and wait for the Quick Tunnel to be ready, then connect by scanning / typing a pairing code from your phone or tablet.

### DSH Web

When using `dsh web`, you can install the plugin into the `web` profile:

```bash
dsh plugin --profile web add "github:AercherC/dsh-remote#main&path:/plugin"
```

Restart `dsh web` after installation, then open:

```text
Settings → Remote Control
```

and enable remote control.

### DSH Desktop

The plugin supports installation with DSH's help directly — no need to quit Desktop or open a terminal.

Send this message in the DSH Desktop conversation:

```text
Install this DSH plugin:
https://github.com/AercherC/dsh-remote
```

DSH completes the installation based on the plugin configuration in this repository. Once installed, open:

```text
Settings → Remote Control
```

Enable remote control, then connect by scanning the QR code or typing a pairing code from your phone.

## Usage

### One-time connection

1. Open “Remote Control” in DSH on your computer.
2. Enable remote control and wait for the Tunnel to be ready.
3. Scan the QR code with your phone, or type in the 8-digit pairing code manually.
4. After pairing succeeds, you enter the DSH Web UI.
5. From then on, that device keeps accessing through its own Device Session.

### Long-term connection

1. In “Remote Control”, switch to “Long-term pairing code”.
2. Generate the long-term code and its QR code.
3. Scan or type in the long-term code with the phone you use regularly.
4. To revoke that credential, click “New code” or set a new custom code.

### Revoking a device

When you stop using a device, revoke it individually from the device list on the computer; when you need every authorized device to lose access immediately, use “Revoke all devices”.

## Security design

- The Remote Gateway listens on `127.0.0.1` only.
- `cloudflared` only establishes outbound connections; no public port needs to be opened on the host.
- The public URL is only a transport entry, not an access credential.
- One-time tickets expire, and are invalidated immediately after successful use.
- The long-term pairing code stays valid until the user actively replaces it.
- Every device has its own session and can be revoked individually.
- Management operations (enable / stop remote access, device revocation, network settings, etc.) only run through the local management channel.
- Pairing claims are rate-limited, and credential comparison is handled in a timing-safe way.
- The sensitive pairing secret in the QR code is placed in the URL fragment, never transmitted as a query parameter.
- When the tunnel process exits, the current public entry is cleared immediately.
- The automatically downloaded `cloudflared` is pinned to a fixed version and verified with SHA-256; on Windows the Authenticode signature is additionally verified.

To keep the long-term code and QR code displayable after restarts, the long-term credential is stored in the plugin state directory. On Windows that directory is restricted to the current user and `SYSTEM`; replacing the long-term code uses atomic overwrite and keeps no history of old codes.

The long-term code is a long-lived credential — please do not share screenshots that contain the long-term QR code or pairing code.
